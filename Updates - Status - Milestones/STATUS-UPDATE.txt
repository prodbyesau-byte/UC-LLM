2. Præcis hvor Codex stoppede
Den tidligere Codex-session stoppede midt i memory/context-systemet.
Den sidste kendte aktivitet var:
🔧 SQLite conversation persistence
Codex var ved at implementere:
- Hele samtalen gemmes permanent i SQLite.
- Alle beskeder bevares.
- Tidligere AI-svar bevares.
- Message edits bevares.
- Chat history skal kunne overleve genstart.
- SQLite skulle integreres direkte med den eksisterende SillyTavern/chat-lagring.
Status: PARTIAL / IN PROGRESS
🔧 Token & Context Manager
Codex var samtidig ved at bygge et system, hvor modellen ikke bare får hele samtalen hver gang.
Planen/implementationen var:
Model Context
│
├── System instructions
├── Conversation summary
├── Relevant older messages
├── Recent messages
├── Relevant web passages
├── Current user message
└── Reserved output tokens
Systemet skulle:
- måle tokenforbruget før modelkald,
- bruge modellens rigtige tokenizer,
- holde requests under modelens context limit,
- reservere plads til svaret,
- opsummere gammel samtale,
- hente relevante ældre beskeder,
- begrænse web research til relevante passager,
- aldrig bare smide hele chatten ind i context,
- afvise request sikkert hvis selv minimum-context er for stort.
Status: PARTIAL / IN PROGRESS
🔧 Context benchmark
Codex var også ved at undersøge:
Hvor stort et context window RTX 3060 6 GB kan håndtere med acceptabel hastighed og RAM/VRAM-reserve.

Repoets config.json står aktuelt til 65,536 tokens, mens tidligere gennemførte tests i README'en beskriver 16,384 tokens.
Det skal derfor benchmarkes/verificeres igen.
Status: INCOMPLETE / NEEDS VERIFICATION
