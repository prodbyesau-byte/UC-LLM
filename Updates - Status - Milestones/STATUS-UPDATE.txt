Persistence og context
----------------------

SillyTavern gemmer chats i sin eksisterende brugerprofil under
`apps/SillyTavern/data/default-user`. Der er ikke en separat SQLite- eller
summarization-service i dette repo, og det skal ikke længere stå som en
halvfærdig implementering.

Context-beregningen håndteres af SillyTaverns OpenAI-connection med
`openai_max_context` fra `config.json` og `openai_max_tokens` til svarplads.
`benchmark-context.py` bruger llama.cpp's `/tokenize` endpoint og måler faktisk
prefill, generation samt RAM/VRAM-headroom. Benchmarken skriver
`logs/context-benchmark.json` og vælger den største konfiguration, der består
af de definerede latency- og memory-kriterier.

Seneste benchmark målte 65.536 tokens som maksimum under testkriterierne
(35,84 sekunders prefill, 32,77 tokens/sekund og 1.084 MiB fri VRAM).
Runtime-konfigurationen er med vilje 16.384 tokens, fordi den giver større
reserve til øvrige Windows-processer. Benchmarken ændrer ikke længere den
aktive `config.json` permanent.

Milestone One local tool subsystem
----------------------------------

Implementeret i denne kildecheckout er en loopback-only, struktureret Tool
Router i `local_tools.py`. Den udvider den eksisterende FileRegistry med
incremental `indexed_files`, `tool_runs`, `file_operations` og audio-cache
tabeller uden database-reset. Files HTTP-endpointet viser både bibliotekets
filer og eksplicit indekserede lokale filer.

Der er centraliseret path-/protected-directory-validering og A/B/C-permissioner.
Move, rename, delete, organize og undo kræver approval; overwrite og permanent
delete kræver eksplicit approval. Delete bruger Recycle Bin via `send2trash`,
eller lokal `.localai-trash` quarantine som fallback. Der findes deterministic
copy/move/rename/folder/delete, undo af move/rename, duplicate hash-scan,
diskanalyse og preview-baseret organize.

Dokumentværktøjerne læser/skriver TXT, Markdown, CSV, DOCX og tekst-PDF lokalt,
og XLSX håndteres som rigtige workbooks via den eksisterende `openpyxl`.
Audioanalyse er deterministic for WAV med metadata, LUFS-estimat, RMS, sample
peak, crest factor, clipping, stereo correlation, bands og cache. Andre
audioformater får metadata hvis `mutagen` installeres; true peak, BPM og key
opdages ikke uden en egnet lokal decoder/estimator og bliver ikke opfundet.
`MULTI_TOOL_TASK`, tool-run persistence og Files UI/API er tilføjet. Test:

```powershell
python -m unittest -v test_file_registry.py test_local_tools.py
```
